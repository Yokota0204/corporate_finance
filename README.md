# corporate_finance

## 環境構築手順

スプレッドシートをコピーして新しい銘柄で使い始めるときの手順です。

1. 「設定」シートの「銘柄コード」（B1）に銘柄コードを入力し、「GAS」メニューの「ファイル名を変更」でファイル名を更新する。
2. 更新後のファイル名を「設定」シートの「シート名（デフォルト）」（B2）に入力する。
   - 「GAS」メニューの「ファイル名をもとに戻す」は、ここに入力した名前に戻します。
3. 「設定」シートの「クラウドプロジェクト番号」をコピーし、スクリプトエディタの「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」→「プロジェクトを変更」から登録する。
4. スプレッドシートの URL からスプレッドシート ID をコピーし、スクリプトエディタの「プロジェクトの設定」→「スクリプト プロパティ」に以下を追加する。
   - URL の `https://docs.google.com/spreadsheets/d/<ここがID>/edit` の部分がスプレッドシート ID です。
5. 「設定」シートの「J_QUANTS_TOKEN」の値をコピーし、同じく「スクリプト プロパティ」に `J_QUANTS_TOKEN` として追加する。

### スクリプトプロパティ一覧

| プロパティ | 値 | 用途 |
|---|---|---|
| `SS_ID` | スプレッドシート ID | Web アプリ（`doPost`）で書き込むスプレッドシートの特定 |
| `J_QUANTS_TOKEN` | J-Quants API のトークン | 銘柄名・財務情報の取得（未設定の場合は「J-Quantsのトークンを取得できませんでした。」のエラーになります） |

> スクリプトは「設定」シートではなくスクリプトプロパティからトークンを読み込みます。「設定」シートの値を変更したときは、スクリプトプロパティも更新してください。

## Web アプリのデプロイ

決算データを `doPost` で受け取ってシートに書き込むには、スクリプトを Web アプリとしてデプロイします。

1. スクリプトエディタ右上の「デプロイ」→「新しいデプロイ」を開く。
2. 「種類の選択」の歯車アイコンから「ウェブアプリ」を選ぶ。
3. 以下のとおり設定して「デプロイ」する（`appsscript.json` の設定と同じです）。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
4. 初回はアクセスの承認を求められるので、画面の案内に従って許可する。
5. 表示された「ウェブアプリの URL」を、決算データの送信元（POST リクエストの送信先）に設定する。

コードを更新したあとは、「デプロイ」→「デプロイを管理」から既存のデプロイを編集し、「バージョン」で「新バージョン」を選んで再デプロイしてください。新しいデプロイを作ると URL が変わります。
