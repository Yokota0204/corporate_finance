# 要求: 3年分以上の財務データを一括で取得・保存できるようにする

- 種別: 仕様変更
- 作成日: 2026-09-25

## 変更・追加する機能の説明（※）

### 現状

- `doPost`（`src/main.ts`）は、リクエストボディの `before`（前期）と `after`（今期）の最大2期分だけを受け取る。
- 受け取った決算を「損益計算」「資産」「キャッシュフロー」の3シートの、A列の最終行の下にそれぞれ追記する。
- そのため、一度のリクエストで保存できるのは2年分まで。

### 変更後

- リクエストボディに新しく `statements`（`FinancialStatement` の配列）を受け付け、**件数の上限なく**（3年分以上も）一括で3シートに追記できるようにする。
- 追記する順番は、送られてきた順ではなく `month` の**古い順（昇順）**に GAS 側で並べ替える。
- 既存の `{ before, after }` 形式も今までどおり使えるようにする（送信側の改修が終わるまでの互換性のため）。
- シートにすでに同じ `month` の行があっても、重複チェックはせず今までどおり追記する。

## 受け入れ条件（※）

- [ ] `statements` に3件以上の決算を入れて POST したとき、3シートすべての最終行の下に、件数分の行が追記される。
- [ ] `statements` が `month` の新しい順・順不同で送られてきても、3シートには `month` の古い順で追記される。
- [ ] `statements` が1件のとき、3シートに1行ずつ追記される。
- [ ] 既存形式 `{ before, after }` で POST したとき、今までと同じく before → after の順で2行追記される。
- [ ] 既存形式 `{ after }` だけで POST したとき、今までと同じく1行追記される。
- [ ] `statements` が空配列、または `statements` も `after` もないとき、エラーになりシートには何も書き込まれない。
- [ ] `statements` と `before`/`after` が同時に送られてきたとき、エラーになりシートには何も書き込まれない（どちらを優先するかの曖昧さを避けるため）。
- [ ] 各シートに書き込まれる列の並び（損益計算: 月〜純利益、資産: 月〜利益剰余金、キャッシュフロー: 月〜配当金の支払額）は現状と同じ。
- [ ] シートに同じ `month` の行がすでにあっても、スキップや上書きはせず追記される。

## 制約事項

- `month` の並べ替えは文字列比較で行う。送信側は `month` を「2024/03」のようにゼロ埋めした同じ形式で送る前提とする（形式が混在すると正しく並ばない）。
- 送信側（決算PDFからJSONを作ってPOSTする仕組み）の改修は今回のスコープ外。
- 重複する `month` の検出・スキップ・上書きは今回のスコープ外。
- 自動テストは Jest + ts-jest を新たに導入して行う。GAS の `SpreadsheetApp` などはモックする。
- GAS のファイル構成（`src/*.ts` をグローバルスクリプトとして `tsc` でビルドし `clasp push`）は変えない。
